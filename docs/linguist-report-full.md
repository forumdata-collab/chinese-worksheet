# 香港小學中文筆順練習簿平台：完整語言學與教育顧問報告

**審核目標：** 為 `chineseword.we1co.me` 建立一套可執行、可驗證、適合香港小學教學的字形、筆畫、筆順、讀音及簡繁轉換規則。

**審核基礎：** 使用者提供的《中文筆順練習簿平台：字形與筆順判斷框架說明》，並輔以相關公開資料作背景參考。

> **重要限制：** 本報告是架構性顧問建議，不代表香港教育局或任何學術機構的正式裁定。個別字形及筆畫爭議仍須逐字核實。

---

## 一、先確立最重要的原則

### 1. 不要把四個不同概念混為一談

| 概念 | 應如何理解 | 平台處理原則 |
|---|---|---|
| 正字 | 涉及規範用字及文字使用標準 | 必須有適用的規範依據 |
| 異體字 | 與另一字形存在特定文字學關係的寫法 | 須核實具體關係，不宜一概而論 |
| 字形 | 一個字的具體書寫形態，包括部件位置及筆畫形態 | 可按香港教學模式採用的代表字形呈現 |
| 筆順與筆畫數 | 書寫次序及筆畫計算結果 | 須按指定標準及具體字形核實 |

**核心建議：EDB 字形優先，不等於所有 EDB 條目都可以直接推導出唯一的正字判斷。**

教育局動畫所呈現的字形可以作為工程上的「代表字形」依據；但若進一步將其稱為唯一正字，或認為社會通用寫法必定屬於異體字，就需要額外的文字學證據。

### 2. 將平台分成三個層次

- **資料層：** 保存原始來源、字形、筆畫數、筆順及讀音。
- **標準層：** 判定資料適用於香港哪一種教學或文字使用情境。
- **呈現層：** 決定學生看到哪個字形、是否顯示其他寫法，以及如何列印工作紙。

例如，資料層可以同時保存「峰」與「峯」的相關資料；標準層決定香港小學練習模式應使用哪種字形；呈現層則決定是否向學生顯示兩種寫法。

這樣可以避免日後因為更換教學政策，就要重新製作整套字形資料。

## 二、官方資料與權威來源：必須界定適用範圍

香港教育局提供《香港小學學習字詞表》及《常用字字形表》等參考資源。這些資料可作為平台的主要核查依據，但不能簡單理解為所有香港漢字在所有情境下均只有唯一、不可變更的官方書寫形式。

相關資源可從教育局的[中文科課程資源頁](https://www.edb.gov.hk/sc/curriculum-development/kla/chi-edu/resources/primary/lang/curriculum-materials.html)查閱。

香港中文學界亦有研究討論香港字形規範與民間書寫習慣之間的差異，例如《香港中文字形問題整理》。相關研究可作背景參考：[研究 PDF](https://chaak.net/assets/pdf/lau-chan-2024-hkglyph-f.pdf)。

香港中文大學《粵語審音配詞字庫》則是粵語讀音與配詞的重要參考來源：[粵語審音配詞字庫](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-can/main.php)。

### 建議修訂的三項原則

| 現行原則 | 建議修改 | 原因 |
|---|---|---|
| EDB 字形就是正字 | EDB 字形是香港教學模式的首選代表字形 | 避免把資料來源與文字學判斷混為一談 |
| EDB 沒有收錄就用其他來源補足 | 後備字形必須標明來源及適用範圍 | 避免學生誤以為所有字形均經香港標準核實 |
| 筆畫數服從實際出貨字形 | 筆畫數須同時符合指定字形、指定計數標準及工作紙一致性要求 | 技術一致不一定等於教學標準一致 |

教育局《香港小學學習字詞表》與《常用字字形表》是相關但不同的資料資源。不能因為某字不在小學字詞表中，就直接推論香港沒有適用的字形資料或筆畫標準。

**總體判斷：保留 EDB 優先架構，但將「唯一正確」改為「指定香港教學模式下的優先採用形式」。**

## 三、逐項回答 10 個顧問問題

## P1｜香港小學應教「峰」還是「峯」？

### 裁定：以香港教學參考字形為預設，但不要把通行寫法當成系統錯誤

這個問題涉及兩個層次：

1. 香港教學模式應選用哪個代表字形？
2. 「峰」與「峯」在文字學上屬於甚麼關係？

兩者不應混為一談。

以「峰／峯」為例，台灣教育部《異體字字典》將「峰」列為正字、將「峯」列為異體字，並指出兩者存在部件位置不同的情況。這是另一個地區的規範及文字學處理方式，不能直接取代香港的選字依據。可參考[台灣教育部《異體字字典》](https://dict.variants.moe.edu.tw/dictView.jsp?ID=12299&la=1)。

### 建議的產品規則

| 使用情境 | 建議顯示 |
|---|---|
| 香港小學練字模式 | 預設顯示經核實的香港教學代表字形 |
| 使用者輸入「峰」 | 保留輸入文字，按設定顯示指定字形 |
| 使用者選擇保留輸入字形 | 顯示輸入字形的對應資料；無可靠資料時不可強行拼湊 |
| 家長或教師查看字形差異 | 提供簡短說明，指出兩種寫法的關係及資料來源 |

### 「說／説」、「衛／衞」等也應同樣處理嗎？

可以採用同一個管理框架，但不能預先認定所有 21 組都屬於完全相同的文字學情況。

清單可能混合不同類型的差異，例如部件位置不同、部件形態不同，以及地區字形習慣差異。應逐組核實，而不是一律以「EDB 正字、另一個是異體字」處理。

### 建議介面文案

不建議：

> 輸入錯誤寫法，系統自動改為正確寫法。

建議：

> 本練習預設採用香港教學參考字形。部分漢字另有通行寫法，可按需要切換。

**優先級：P0。** 這項決定會影響字形歸一、輸入處理、異體字標籤及網站可信度。

## P2｜「異體字」與「異體字形」應否分開？

### 裁定：應分開，這是目前資料模型的重要缺口

平台目前把「異體」定義為與正字同義、寫法不同，而且由 EDB 以同一動畫 ID 處理的字。這個定義方便工程實作，但將來源系統的處理方式直接當成文字學定義，並不充分。

建議至少區分以下情況：

| 類別 | 意義 | 注意事項 |
|---|---|---|
| 異體字 | 不同字形在特定意義下代表同一個字 | 須有文字學或權威資料支持 |
| 字形變體 | 同一字在部件形態或局部筆形上存在差異 | 不能一概當成另一個字 |
| 地區字形差異 | 不同地區採用的規範或慣用字形不同 | 須記錄適用地區及依據 |
| 簡繁關係 | 簡化字與繁體字之間的對應 | 不應自動等同異體字關係 |
| 待核實 | 尚未有足夠資料確認關係 | 不應自動歸一 |

### 建議資料模型

```json
{
  "character": "峰",
  "preferredGlyph": "峯",
  "relationship": {
    "type": "variant",
    "status": "needs_review",
    "source": "EDB",
    "note": "需核實香港教學代表字形與輸入字形的關係"
  }
}
```

以上只是結構示意，並非對「峰／峯」關係的最終文字學裁定。

建議關係類型可採用：

- `variant_character`
- `glyph_variant`
- `regional_form`
- `simplified_traditional`
- `unverified`

應分開記錄「關係類型」與「資料來源」。同一組字在不同地區的規範資料中，可能會有不同分類方式。

**優先級：P0。** 錯誤的關係分類會傳播到整個平台。

## P3｜筆畫數應跟 EDB、課本，還是字形本身？

### 裁定：區分「字形實際筆數」與「教學採用筆畫數」

平台目前以實際出貨字形的筆數為準，確保卡片、描紅格及筆順工作紙一致。這個原則有工程合理性，但仍須補上一層。

同一字形的實際路徑數，與某個教學標準所認定的筆畫數，不一定可以互換。

建議把筆畫資料拆成三項：

1. `glyph_stroke_count`：字形檔內實際包含多少筆。
2. `standard_stroke_count`：指定標準對該字採用的筆畫數。
3. `worksheet_stroke_count`：實際用來生成逐筆工作紙的筆數。

正常情況下，三者應一致。若不一致，系統不應默默選擇其中一個數字，而應標記為待核實。

### 如何處理艹、辶、阝、糹、骨、為等部件？

不建議建立一張簡單的「三地部件筆畫換算表」，再對所有漢字直接套用，原因包括：

- 不同地區可能採用不同的筆畫計算慣例。
- 同一部件在不同字形中，可能有不同的實際書寫形式。
- 部件名稱、字形及筆畫計數不能任意互相推導。

對於不在 EDB 字詞表中的 33 個個案，可以繼續提供練習，但應標示為後備資料，不能直接宣稱全部符合香港教學標準。

### 建議介面標籤

- **香港教學參考字形：** 筆畫數已按指定香港資料核實。
- **後備字形：** 筆畫數按所採用的字形資料計算，未必與香港教學參考資料一致。
- **待核實：** 尚未取得足夠資料確認筆畫數。

這些標籤只應在符合相應條件時使用，不能只根據資料來源名稱自動宣告已完成核實。

## P4｜「為／爲」、「臺／台」、「撝」等爭議個案應如何處理？

### 裁定：不要以單一來源的筆畫數直接推論正字地位

這組問題包含三個不同判斷：

1. 哪一個字形適用於香港教學模式？
2. 指定字形應如何計算筆畫？
3. 這個字與其他寫法的文字學關係是甚麼？

### 個案 A：「為」與「爲」

如果平台採用的香港參考字形是九畫，就應在該模式中按已核實的九畫資料生成工作紙。

但不能因此推論所有字典、所有地區及所有相關字都必須採用相同的計數結果。

### 個案 B：「撝」的 12 畫與 15 畫

平台目前按採用的「為」形及相關字形資料推算為 12 畫，其他來源則標示 15 畫。

這個差異尚不足以單獨證明任何一方錯誤。應進一步檢查：

- 兩邊使用的是否同一個 Unicode 字元。
- 實際採用的是哪一種字形。
- 筆畫分解是否一致。
- 計數差異是否來自部件的書寫慣例。
- 是否有香港適用的參考資料可以核實。

在完成檢查前，應標記為「跨來源筆畫數有差異」，而不是直接宣布 12 畫或 15 畫是唯一正確答案。

### 個案 C：「臺／台」

「臺」與「台」在現代中文中具有特定的使用關係，但不能在所有語境下無條件互換。地名、詞語、專名及一般用字都可能涉及不同的選字要求。

因此，不應單憑查詢頁出現「轉自」提示，就把整個平台的「臺」全部轉成「台」。

建議：

- 保留使用者輸入的原始字元。
- 將教學代表字形獨立儲存。
- 只有在已確認字詞及語境適用時，才進行字形歸一。
- 對無法確認的個案，保留原字並標示待核實。

至於「撝」的筆畫數，以及「臺／台」的具體香港教學裁定，仍需要逐字核查原始資料。

## P5｜粵語字「嘅、咗、喺、嗰」使用台灣教育部字形是否合適？

### 裁定：可以作為後備來源，但不應標示為已核實的香港標準字形

平台目前使用 twpen 為部分香港粵語字提供字形資料，並在頁腳標明來源。這是合理的工程後備方案，但必須區分：

- 有一個可供書寫的字形。
- 這個字形已符合香港粵語教學的適用要求。

兩者並不等同。

香港中文大學《粵語審音配詞字庫》是重要的粵語讀音及配詞參考資料，適合核對讀音，但不能單憑其讀音資料，就認定某個字形已符合香港小學的筆順教學要求。

### 建議的字形來源分級

| 分級 | 資料狀態 | 介面建議 |
|---|---|---|
| A | 香港教學參考資料已核實 | 香港教學參考字形 |
| B | 有可靠的香港粵語文字資料，但沒有核實筆順 | 粵語字形；筆順尚未核實 |
| C | 採用台灣教育部資料 | 後備字形：來源為台灣教育部 |
| D | 採用通用字形資料 | 通用字形：未經香港教學標準核實 |
| E | 沒有可靠字形資料 | 暫不提供逐筆描紅 |

這是建議的平台內部分級，不是官方分類。

### 是否應尋找其他香港來源？

可以優先核查：

- 香港中文大學的粵語及漢字資料。
- 香港教育局的相關學與教資源。
- 香港本地字典及粵語文字研究。
- 可靠的漢字字形研究或字典資料。

必須強調：粵語讀音權威不等於粵語字形權威，粵語字形權威亦不一定提供逐筆筆順。

## P6｜一字多音，小學生應顯示一個讀音還是全部讀音？

### 裁定：預設顯示常用主讀音，其他讀音按需要展開

對小學練字簿而言，顯示全部讀音不一定能幫助學生學習。若把所有讀音直接列在工作紙上，學生可能不知道默書或組詞時應採用哪一個。

另一方面，完全隱藏其他讀音，也可能令家長及教師誤以為這個字只有一種讀法。

### 建議採用三層顯示

**第一層：小學練字模式**

顯示：
- 一個適用於指定詞語的讀音。
- 粵拼。
- 普通話拼音（如有需要）。

**第二層：字詞學習模式**

顯示：
- 常用讀音。
- 每個讀音對應的詞語。
- 簡短的意義或用法說明。

**第三層：進階查字模式**

顯示：
- 已核實的其他讀音。
- 異讀字註記。
- 資料來源及必要說明。

### 重要修正

不要單純把 CUHK 網頁的首行讀音當成所有情境下的唯一主讀音，也不應只因某個讀音被標為「異讀」，就自動將其排除。

應按以下次序判斷：

1. 學生正在學習哪個詞語。
2. 詞語的實際讀音。
3. 資料來源如何處理該讀音。
4. 該讀音是否適合所選教學模式。

**建議預設策略：主讀音加詞例，其他讀音可展開。**

## P7｜「直出異體字」應否預設開啟？

### 裁定：預設關閉，維持現行決定

平台主要服務香港小學練字及工作紙列印。若同一份工作紙中，部分字形按照香港教學參考資料顯示，部分字形又按照使用者輸入直接顯示，學生可能難以分辨哪個是本次練習要求掌握的字形，以及哪些差異只是字形不同。

### 建議的功能定位

| 模式 | 設定 | 用途 |
|---|---|---|
| 香港教學模式 | 預設開啟 | 以經核實的香港教學代表字形製作工作紙 |
| 保留輸入字形 | 由使用者選擇 | 盡可能保留輸入字形 |
| 字形比較模式 | 由使用者選擇 | 讓教師及家長比較不同寫法 |

目前有 12 個字支援直出異體字，另有 8 個字因替代字形與筆畫數不同而暫不支援。這個限制應保留，不應為了令所有字都能切換，而把筆畫數不一致的替代字形強行接入工作紙。

系統應按字形資料的完整程度決定能否切換：

- 有完整、經驗證的替代字形及筆順：允許切換。
- 有替代字形，但筆畫數或筆順不一致：暫不支援。
- 沒有可靠替代字形：顯示原因，不自行推導。

建議把「直出異體字」改成 **「保留輸入字形」**。這個名稱對家長和教師更容易理解，也不會預先假定所有不同寫法都屬於異體字。

## P8｜能否根據部首、聲符或《康熙字典》推導缺字字形？

### 裁定：不應用於正式出貨字形

平台已對 70 個有官方真值的字進行盲測，結果顯示筆畫數正確率為 36%、平均墨跡重疊度為 0.41，而筆順完全相同的測試結果亦很低。因此，停止以部件推導字形出貨是合理決定。

**知道一個字由甚麼部件組成，不代表知道這些部件在指定字形中應如何書寫。**

即使兩個字具有相同部件，仍可能出現：

- 部件形態不同。
- 筆畫數不同。
- 部件位置不同。
- 筆畫連接方式不同。
- 筆順不同。

例如，「手」與「扌」、「水」與「氵」並不能在沒有額外規則的情況下直接互換。

### 建議規則

1. 有可靠的逐筆字形資料：正常出貨。
2. 有部件資料，但沒有完整字形：可用於內部研究，不用於正式描紅。
3. 只有通用字形資料：可按後備模式出貨，清楚標示來源。
4. 沒有可靠資料：暫不提供逐筆練習。

《漢字部件表》可用於部件識別及資料分析，但不應被視為自動生成完整字形的充分依據。

## P9｜標點符號應否佔格？位置是否需要調整？

### 裁定：標點應佔格，但必須與漢字描紅分開處理

平台目前讓每個全形標點符號佔一格，但沒有真正的筆畫資料。這是合理的基礎設計。

標點與漢字的書寫要求不同，因此不應把標點當成普通漢字處理。

### 建議規則

| 標點 | 建議處理 |
|---|---|
| ，、。 | 各佔一格，採用一致的標點排版規則 |
| ！？ | 各佔一格，按標點形態調整位置 |
| ：； | 各佔一格，採用適當的垂直排列 |
| 「」『』 | 按中文標點的配對規則處理 |
| （）《》 | 各佔一格，保持配對及排版一致 |
| 英文標點 | 按實際文字及選定的排版模式處理 |

以上是建議的版面規則，並非聲稱香港所有教材均使用完全相同的標點位置。

### 是否需要逐筆描紅？

目前不建議優先開發。可以先採用以下方式：

- 保留文字及標點。
- 提供格線。
- 顯示淡色標點示範。
- 不顯示筆順數字。
- 不納入漢字筆畫數統計。

日後若要教授標點書寫，再獨立建立標點字形資料。

## P10｜是否需要逐字標示字形來源？

### 裁定：列印版不需要逐字標示，但應提供可追溯的資料

一張工作紙可能混合 EDB、twpen 及 HanziWriter 的字形。頁腳作統一聲明有助保持版面整潔，但平台仍需要更精細的來源記錄。

### 建議採用兩種呈現方式

**A. 學生工作紙**

保持整潔，不必在每個字旁邊加上來源標籤。

建議頁腳文案：

> 本工作紙以香港中文教學參考資料為優先；部分字形、筆順及讀音資料取自其他字形資料庫。不同來源的資料可能存在差異，請按教師指定的教材及字形要求使用。

正式上線前，應確認文案與實際資料覆蓋情況一致。

**B. 教師／家長檢查模式**

點擊單字後，可以查看：

- 原始輸入字。
- 實際顯示字形。
- 字形來源。
- 筆順來源。
- 筆畫數來源。
- 讀音來源。
- 是否經人工核實。
- 是否存在其他已知寫法。

### 是否需要逐字人工核實？

對於小學核心字詞及存在重大爭議的字，應優先人工核實，不必一次過審查全部 5,557 個字。

建議先集中處理：

1. 香港小學核心字詞。
2. 筆畫數不一致的字。
3. 正字與通行寫法有爭議的字。
4. 香港常用粵語字。
5. 曾經發現筆順中線方向錯誤的字。

## 四、另外兩項必須處理的問題

## 1. 香港常用詞表應如何用於簡繁轉換？

平台目前採用 OpenCC 詞組優先、逐字轉換及香港字形歸一的流程。這個架構可以保留，但應明確區分：

- **文字轉換：** 把簡體字轉成繁體字。
- **詞語辨義：** 判斷一個字在特定詞語中應採用哪個繁體形式。
- **香港字形選擇：** 選擇符合指定香港教學模式的字形。

這三個階段不能全部交由同一個逐字替換規則處理。

例如「發／髮」、「乾／幹」、「後／后」、「隻／只」等，都需要考慮詞語及語境。

### 建議的轉換優先次序

1. 完整詞組對照。
2. 已核實的香港常用詞語表。
3. 經核實的單字對照。
4. 無法判斷時保留待核實狀態。

對於可能改變詞義的情況，不應只為了讓文字全部轉換成繁體，就自動猜測。

香港教育局的《香港小學學習字詞表》及相關學與教資源，可作為建立詞語核查資料的起點：[教育局中文科課程資源](https://www.edb.gov.hk/sc/curriculum-development/kla/chi-edu/resources/primary/lang/curriculum-materials.html)。

建議將香港小學常用詞表定位為詞語辨義及教學選字的參考資料，而不是所有簡繁轉換的唯一依據。

此外，應保留轉換前的原始字串，並為重要轉換記錄所使用的詞組規則，以便日後修正。

## 2. 是否需要製作「香港小學常用字正字、異體、筆數及筆順對照表」？

**需要，而且建議將它列為下一階段的核心工作。**

這張對照表不只是教師附錄，更應成為平台的品質控制資料庫。

### 建議欄位

| 欄位 | 用途 |
|---|---|
| 字元 | 原始 Unicode 字元 |
| 香港教學代表字形 | 預設顯示形式 |
| 其他通行寫法 | 已核實的相關字形 |
| 關係類型 | 異體字、字形變體、地區形式等 |
| 字形來源 | EDB、twpen、HanziWriter 等 |
| 筆順來源 | 實際採用的筆順資料來源 |
| 字形筆畫數 | 字形檔中的實際筆數 |
| 教學筆畫數 | 指定教學標準採用的筆數 |
| 粵語讀音 | 粵拼及相關詞例 |
| 普通話讀音 | 拼音及必要的詞例 |
| 核實狀態 | 自動驗證、人工核實、待核實 |
| 備註 | 存在的爭議及處理決定 |

### 建議的資料品質分級

- **A 級：** 香港教學參考資料及實際字形均已核實。
- **B 級：** 有可靠後備資料，筆畫數與筆順已完成內部驗證，但未有足夠證據確認符合香港教學標準。
- **C 級：** 有可用字形，但筆畫數、筆順或相關字形關係尚未完成核實。
- **D 級：** 資料不足，不提供正式逐筆描紅。

這是建議的平台內部品質分級，不是教育局的官方分類。

## 六、建議的實施次序

不要立即全面重寫字形資料庫。現有的驗證工具已具備良好基礎，應先修正判斷規則，再決定哪些資料需要更新。

### 第一階段：修正定義及資料模型

先處理：

- 正字與代表字形的區別。
- 異體字與字形變體的區別。
- 原始輸入字與顯示字形的分離。
- 字形筆數與教學筆畫數的分離。

**目標：避免系統把尚未核實的文字學判斷寫死在資料庫中。**

### 第二階段：核查高風險字

優先核查：

- 目前列出的 21 組字形爭議。
- 另外 8 個暫不支援直出字形的字。
- 33 個沒有 EDB 字詞表資料、曾修改筆畫數的字。
- 「為」、「撝」、「臺」、「台」等爭議個案。
- 常用粵語字。
- 已發現筆順中線方向異常的字。

這些數量及個案來自原始審核文件；此處提出的是審查次序，並不代表已完成逐字核實。

### 第三階段：建立教師檢查模式

讓教師能查看：

- 字形來源。
- 筆順來源。
- 筆畫數依據。
- 字形關係。
- 核實狀態。

這比在學生工作紙上加入大量說明更有效。

### 第四階段：建立可重跑的文字學審核流程

每次新增或修正字形資料時，記錄：

1. 原始來源。
2. 修改前後的差異。
3. 修改理由。
4. 是否影響筆畫數。
5. 是否影響筆順。
6. 是否需要人工覆核。
7. 是否影響既有工作紙。

這能讓工程師在日後更新資料時，分辨某項修改究竟是技術修正，還是文字學判斷的改變。

## 七、最終顧問結論

**工程架構值得保留，最需要升級的是文字學分類及資料品質管理，而不是重新製作整套字形。**

目前值得肯定的地方包括：

- 已建立逐字字形資料。
- 已處理不同來源的筆順差異。
- 已驗證大量筆順數字的位置。
- 已發現並停止不可靠的部件推導。
- 已有自動化驗證及介面回歸測試。
- 已注意到香港教學與其他地區字形之間的差異。

不過，有三項決定應立即確立：

**第一，EDB 代表字形應是香港教學模式的優先依據，但不應直接等同於所有情況下的唯一正字。**

**第二，字形、筆順、筆畫數、讀音及異體字關係必須分開管理。任何一個來源的權威性，都不能自動延伸到其他資料欄位。**

**第三，對未經核實的字形，寧可清楚標示限制，也不要為了提高字庫覆蓋率而製造看似完整、實際上不可靠的練字資料。**

這三項原則比單純增加字庫數量更重要。

### 證據界線

教育局資料、香港中文大學的粵語資料，以及相關字形研究，足以支持上述架構性建議；但本報告並未逐一重新擷取全部 EDB 動畫，也未完成 21 組爭議字、33 個筆畫個案及全部後備字形的獨立文字學審查。因此，對這些個別漢字的最終裁定，仍應保留待核實狀態。

**最終建議：保留現有平台與驗證工具，以「香港教學參考模式＋逐字來源追溯＋爭議個案核實」作為下一階段的核心方向。**
