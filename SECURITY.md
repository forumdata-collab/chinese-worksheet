# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (main) | ✅ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately through the [GitHub Security Advisory](https://github.com/forumdata-collab/chinese-worksheet/security/advisories/new) ("Report a vulnerability" button), or email the maintainer directly.

We aim to acknowledge reports within **48 hours** and will keep you informed of progress until the issue is resolved.
