iPhone / iPad 安裝

用 AltStore 安裝，免費 Apple ID 即可（不用開發者帳號）。App 完全離線，唔需要連線都用得。

一、先裝 AltStore

  1. 電腦（Mac 或 Windows）安裝 AltServer
  2. iPhone 用 USB 連電腦，AltServer 選單 → Install AltStore → 揀你部機，輸入 Apple ID
  3. 之後可以在 iPhone 直接用（首次要在「設定 → 一般 → VPN 與裝置管理」信任 AltStore）

二、加入本站 source

AltStore → Browse → 右上角 +，貼上：

https://raw.githubusercontent.com/forumdata-collab/chineseword-ios/main/altstore-source.json

三、安裝

Source 入面見到「中文筆順練習簿」→ 按 Free / Get，AltStore 會用你嘅 Apple ID 重新簽署並安裝（約一分鐘）。

用 AltStore 直接開啟 下載 IPA（手動安裝） Android 安裝

關於 7 日有效期：免費 Apple ID 簽署的 App 每 7 日要重新簽署一次；只要 AltServer 同手機喺同一個 Wi-Fi，AltStore 會自動背景續簽（保持 AltServer 開住）。付費開發者帳號則為 1 年。
版本：v2.36（build 40）· 最低 iOS 15.0 · 完全離線 · 不收集任何資料。
