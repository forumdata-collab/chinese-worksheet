## 暫緩方案（item 3）：部件推導字形

已完成實驗，**結果唔達標**，暫不出街：

- 做法：由 IDS 拆部件 → 用「同部首 EDB 字」抽真實部首形（含 部件變形）＋「同聲符 EDB 字」抽右部件 → 按 operator 次序組合。
- 盲測 70 個**有官方真值**嘅字（`/tmp/synth.py`、`/tmp/synth2.py`、`/tmp/synth_fidelity.py`）：
  - 筆畫數正確 **36%**
  - 墨跡 IoU 平均 **0.41**（明顯唔似）
  - 筆順 identity 只 **2/17**
- 根因：部件在合體字內會變形（手→扌 4→3 畫、水→氵、心→忄、衣→衤），而要把模板字「切返」成部件，本身就需要嗰份我哋想求嘅分解 → 循環依賴。
- 如要繼續，可行路線（需要更多時間）：
  1. **受限筆畫抽取（constrained stroke extraction）**：以官方字形輪廓（EDB／HKSCS／zdic hk SVG）為輸入，骨架化後按「已知筆畫類型序列」（漢典笔顺编号／全字庫筆順）切段，再分配輪廓片段。相對於盲目分解，類型序列係非常強嘅約束。
  2. 檢查**全字庫 CNS11643** 開放資料集係否含逐字筆順資料（若有，可能一次過覆蓋大部分長尾字）。
  3. 若只求「字形參考」：可用 zdic `kai/hk` SVG 或 HKSCS 政府參考字型作示範字形（但無筆順動畫）。
